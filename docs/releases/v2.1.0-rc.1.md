# Noctella ERP/Web v2.1.0-rc.1

- Release type: Release Candidate
- Package version: `2.1.0-rc.1`
- Git tag planned: `v2.1.0-rc.1`
- Base branch: `main`
- Release status: staging acceptance pending

This is the first Noctella release where the package versions across the monorepo
(root, `apps/api`, `apps/admin`, `apps/storefront`, `packages/shared`) and the Git
release tag are aligned. Prior tags (`v1.4`–`v1.9`, `v2.0.0-rc.1`) were cut while every
`package.json` remained at `0.1.0`.

## Validated capabilities

- Product and inventory management, with EUR-based pricing and stock tracking
- Product-photo upload, ordering, primary-photo selection, and persistence
- Admin product, order, offer, and background-job workflows
- Storefront catalog and product detail pages
- SEO and metadata for storefront pages
- Cart and guest "Make an Offer"
- Mock checkout and order creation
- Order cancellation with inventory restoration
- SQLite and product-photo restart persistence
- Stale product-photo outbox lock recovery
- Production-safe mock-payment gate (mock providers disabled by default outside staging)
- Admin `(mock)` payment-provider labeling
- Fail-closed marketplace webhook signature verification
- CORS, secure-cookie, scheduler-auth, and secret-safety hardening
- Successful workspace CI validation (typecheck, test, build, lint)

Marketplace integrations (eBay, Etsy, WooCommerce) are not active in this release.

## Known limitations

- Live staging acceptance has not yet been completed
- Production deployment has not occurred
- Real Stripe and PayPal integrations do not exist
- Payment providers are mock-only
- Automated refunds do not exist
- Automated off-disk SQLite and product-photo backups do not exist
- SQLite deployment must remain single-instance
- eBay, Etsy, and WooCommerce integrations are not active
- Some non-blocking Admin UX and observability work remains deferred

Nova Vita ex Praeterito.
