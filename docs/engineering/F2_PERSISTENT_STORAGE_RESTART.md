## Act: minimal versioned evidence, no schema migration

The existing identity columns are TEXT (including copy_dev up to64 characters). New confined W2/W4 seals encode pfs1:<32 lowercase filesystem UUID hex>:<positive inode birth nanoseconds> in dev; ino stays an exact decimal string. Copy records use the same version with their OWN inode birth, plus the existing separate birthNs and retained staging name. Maximum encoded length59 fits the existing64-character bound. No schema/migration/0042 change and no historical row rewrite are needed. Numeric legacy identity is never silently converted.

The reviewed-source launcher gains a read-only --storage-proof mode. It receives the already-open descriptor as fd3 and uses Linux FS_IOC_GETFSUUID to obtain the external on-disk UUID. It refuses root, wrong descriptor types, unsupported ioctl, missing/zero/short UUID, and performs no exec, file mutation, privilege change or confinement relaxation in this mode. Normal launcher/confinement execution remains unchanged. The API invokes it with bounded output/time and no DB/provider environment. Caller-supplied labels, st_dev changes and hash equality are never UUID evidence. fstat before/after verifies the descriptor still names the observed inode/birth.

Kernel contract: [Linux6.9 UAPI](https://github.com/torvalds/linux/blob/v6.9/include/uapi/linux/fs.h) and [ioctl implementation](https://github.com/torvalds/linux/blob/v6.9/fs/ioctl.c). This generic ioctl requires a supporting kernel/filesystem; unsupported targets fail readiness. statfs f_fsid is deliberately not substituted because its definition is filesystem/OS-specific. Full128-bit on-disk UUID is required; there is no label, boot-time device-number or hash fallback. Storage administration must preserve the same filesystem and must not substitute clones with duplicated filesystem UUIDs. A bit-for-bit cloned filesystem/DB with duplicated UUID is outside the trusted-storage configuration, not an authorization mechanism; no unrelated root/DB-admin RBAC or signature system is introduced.
